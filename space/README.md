# SEC 10-K RAG — live demo

Ask questions about the 10-K annual reports of Apple, Microsoft, NVIDIA, Alphabet and
Amazon. Every answer cites the filing excerpts it was built from, and the system refuses
when the excerpts don't contain the answer.

Code, evaluation and write-up: **https://github.com/TuAnh-Vo/sec-10k-rag**
